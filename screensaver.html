Set Frame as your TV screensaver

Android TV requires a one-time permission grant via ADB before apps can change the system screensaver.

  1. On a computer, install Android platform-tools (adb) from developer.android.com (or brew install android-platform-tools on macOS).
  2. On your TV: open Settings › System › About, tap Android TV OS build 7 times to enable Developer options, then open Developer options › Wireless debugging (or USB debugging) and pair.
  3. Connect from your computer (replace <TV-IP>:<port> with the address shown on your TV):
    adb connect <TV-IP>:<port>
  4. Grant Frame permission to update the screensaver:
    adb shell pm grant tv.bengry.gphotoswallpaper android.permission.WRITE_SECURE_SETTINGS
  5. Go back to Frame › Settings › Screensaver on your TV and press Check again, then select Set Frame as screensaver.
